# The hosted calculator's only dependency, and it exists for exactly one thing:
# verifying the Atlassian-issued invocation token in SERVICE_AUTH=forge-token.
#
# Deliberately not in scripts/requirements.txt. The security suite asserts the
# fetcher's dependency list stays at one, and that assertion is worth keeping —
# the fetcher is what holds a customer's credentials, and its supply chain is
# the one to keep boring. This service holds no credential and reaches no
# tracker, so it is the right place for the crypto.
#
# Everything else here is the standard library, still. In shared-secret mode
# this file is not needed at all: `_verify_forge_token` imports jwt inside the
# function, and the startup guard refuses the token mode if the import fails.
PyJWT[crypto]>=2.8,<3
