# The dashboard does not measure people

There is no hours, overtime or timesheet field anywhere — not in the schema, the fetcher, the import pipeline, the UI or the documentation — and no report ranks or compares individuals. An earlier version of this dashboard charted output-per-person against recorded overtime; both were removed.

Two reasons, and they are different. A time-tracking field implies a regime this organisation does not operate, and its mere presence in a template invites someone to start filling it in. Individual throughput comparison is a claim the data cannot support: throughput is a property of the system, and the first report that ranks people is the last report anyone reads honestly.

The replacement is team load — work in progress and unplanned work, both derived from issue status alone. Ownership counts are fine; league tables are not. If a proposed metric appears to need effort data, it is the wrong metric.
